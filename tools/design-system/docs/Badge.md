A small pill label for tags and statuses.

- `variant`: `default` (yellow, for one highlight), `secondary`, `muted` (outlined, `muted-foreground` text: the site's technology tags), `outline`, `destructive`.
- Lay tag lists out with `flex flex-wrap gap-2`.

```jsx
<Badge variant="muted">Nuxt</Badge>
```

React mirror of the site's shadcn-vue `Badge`; classes copied from `app/components/ui`.
